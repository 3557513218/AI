# 知识库使用说明

将你想要 AI 查询的资料放在 `knowledge/` 目录下，支持 `.md`、`.txt`、`.json`、`.csv` 格式。

## 示例：人员信息

创建一个 `员工信息.md` 文件，内容如下：

```markdown
# 员工信息

## 技术部
- 张三 - 技术总监，2019年入职，负责技术架构
- 李四 - 高级前端工程师，2020年入职，负责前端开发
- 王五 - 后端工程师，2021年入职，负责 API 开发

## 市场部
- 赵六 - 市场总监，2018年入职，负责市场推广
- 钱七 - 品牌经理，2020年入职，负责品牌管理
```

## 示例：组织架构

创建一个 `组织架构.md`：

```markdown
公司成立于2018年，总部位于广州
目前有员工200人
下设技术部、市场部、人事部、财务部
```

## 工作原理

当用户提问时，系统会自动在 `knowledge/` 目录下搜索与问题相关的资料，将匹配到的内容作为参考信息注入到 AI 的上下文中，AI 会优先基于这些资料回答，而不是凭空编造。
